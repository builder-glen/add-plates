# gym-points PRD

> 2026-09-03 · 작성 중 (기능 단위로 계속 붙여나감)

## 이게 뭔가

헬스장에서 **지난번 기록을 보면서** 오늘 운동을 기록하는 모바일 웹앱.

메모장으로도 기록은 된다. 이 앱이 필요한 이유는 하나다 —
바 앞에 섰을 때 **"지난주에 몇 kg 들었지"가 저절로 떠 있는 것.**

## 누가 쓰나
1차는 나 혼자, 이후 헬스하는 지인 10명 안쪽.

## 정해진 것
| | |
|---|---|
| 기록 최소 단위 | 세트 하나 (세트마다 무게가 다르니까) |
| 종목 유형 | 웨이트 + 맨몸. 유산소·시간 종목은 나중에 |
| 하루 운동 횟수 | 여러 번 가능 (아침/저녁 분리) |
| 로그인 | 구글만 |
| 구글 캘린더 | 앱이 일정을 관리하고, 원하면 캘린더로 내보내기 |
| 신체 정보 | 측정할 때마다 이력으로 쌓기. 전부 선택 입력 |
| 인프라 | Supabase + 정적 SPA 호스팅. 월 $0 |

# 1. 로그인한다

내 기록만 나에게 보이게 하는 것이 목적. 그 외에 하는 일이 없다.

| 사용자 | 시스템 |
|---|---|
| 앱을 처음 연다 | 로그인 화면. 구글 버튼 하나만 있다 |
| 구글 버튼을 누른다 | 구글 계정 선택 화면이 뜬다 |
| 계정을 고른다 | 오늘 날짜 화면으로 들어간다 |
| 다음에 다시 연다 | 로그인 없이 바로 들어간다 |
| 설정에서 로그아웃한다 | 로그인 화면으로 돌아간다 |

**이럴 땐 이렇게**
- 로그인 안 한 채로 주소를 직접 치고 들어오면 → 로그인 화면으로 보낸다
- 구글 계정 선택을 도중에 취소하면 → 로그인 화면 그대로. 에러 문구는 띄우지 않는다
- 다른 사람 계정으로 들어가면 → 그 사람 기록만 보인다. 내 기록은 안 보인다

**되면 성공**
- 다른 계정으로 내 기록을 조회하면 0건 (앱 코드가 아니라 DB가 막는다)
- 새로고침하거나 앱을 껐다 켜도 로그인이 유지된다

# 2. 오늘 운동을 기록한다 ← 핵심

> 헬스장. 벤치프레스 첫 세트를 막 끝냈다. 다음 세트까지 60초.

| 사용자 | 시스템 |
|---|---|
| 홈 화면 아이콘으로 앱을 연다 | 오늘 날짜 화면이 뜬다 |
| `[+ 운동 추가]`를 누른다 | 종목 선택 시트가 올라온다 |
| `ㅂㅊㅍ`를 친다 | 벤치프레스가 첫 줄에 뜬다 |
| 벤치프레스를 누른다 | 시트가 닫히고 종목 카드가 생긴다<br>**지난주 기록(70kg × 8, 8, 6)이 같이 보인다** |
| `70`, `8`을 넣는다 | 1세트가 저장된다<br>2세트 줄이 생기고 `70 / 8`이 미리 채워져 있다 |
| `[+세트]`를 누른다 | 2세트가 저장된다 |
| `[+ 운동 추가]`로 다음 종목 | 위 과정 반복 |

**이럴 땐 이렇게**
- 그날 첫 기록이면 → 세션이 알아서 만들어진다. 이름도 시간 보고 자동으로 붙는다 ("오전 운동")
- 처음 하는 종목이면 → "첫 기록입니다"가 뜨고 입력란은 비어 있다
- 맨몸 종목(풀업 등)이면 → 무게 칸이 아예 안 나온다. 횟수만 넣는다
- 무게가 2.5kg 단위면 → 소수점 입력된다 (`62.5`)
- 무게나 횟수가 0이면 → 저장되지 않는다
- **통신이 끊기면** → 화면엔 저장된 것처럼 보이고 뒤에서 계속 재시도한다.<br>끝내 실패하면 그 줄만 빨갛게 되고 `[재시도]`가 뜬다

**되면 성공**
- 앱 열고 1세트 저장까지 **15초 안에** 끝난다
- 3세트를 같은 무게로 하면 탭 2번으로 끝난다
- 지하 헬스장에서 통신이 끊겨도 입력이 멈추지 않는다

---

# 3. 종목을 찾는다

장갑 낀 손, 손에 땀. `벤치프레스` 5글자를 정확히 치는 건 무리다.

| 사용자 | 시스템 |
|---|---|
| 종목 선택 시트를 연다 | 최근 쓴 종목 10개가 먼저 보인다 |
| `ㅂㅊㅍ`를 친다 | 초성이 맞는 종목이 나온다 |
| `벤치`를 친다 | 이름에 들어간 종목이 나온다 (벤치프레스, 인클라인 벤치프레스…) |
| `벤프`를 친다 | 별칭이 맞는 종목이 나온다 |
| 부위 탭에서 `등`을 누른다 | 등 종목만 걸러진다 |
| 종목을 누른다 | 시트가 닫히고 기록으로 이어진다 |

**이럴 땐 이렇게**
- 타이핑할 때마다 → 즉시 반응한다. 서버에 물어보지 않는다
- 처음 쓰는 사람이라 최근 종목이 없으면 → 부위 탭이 먼저 보인다
- 검색 결과가 하나도 없으면 → `+ '{친 글자}' 직접 추가`가 뜬다 (7번으로)

**되면 성공**
- `ㅂㅊㅍ` / `벤치` / `벤프` 셋 다 벤치프레스가 나온다
- 검색하는 동안 통신을 전혀 쓰지 않는다

# 4. 하루에 두 번 운동한다

아침에 유산소, 저녁에 웨이트. 둘을 섞지 않고 따로 남긴다.

| 사용자 | 시스템 |
|---|---|
| 아침 운동을 기록한다 | "오전 운동" 세션이 생긴다 |
| 저녁에 앱을 연다 | 아침 기록이 그대로 보인다 |
| `[+ 세션 추가]`를 누른다 | 아래에 두 번째 세션이 붙는다. 이름은 "저녁 운동" |
| 종목을 추가한다 | 두 번째 세션에 들어간다 |
| 세션 이름을 누른다 | 이름을 고칠 수 있다 |

**이럴 땐 이렇게**
- 그날 세션이 하나뿐이면 → 세션 이름줄이 눈에 안 띄게 들어간다.<br>하루 한 번만 하는 사람은 이 기능이 있는지도 몰라야 한다
- **저녁 세션에 벤치를 추가하면** → 지난 기록은 오늘 아침 게 아니라 **지난주 것**이 뜬다.<br>보려는 건 오늘 안의 변화가 아니라 주 단위 진척이기 때문
- 종목을 다 지워서 빈 세션이 되면 → 화면에서 숨긴다

---

# 5. 지난 기록을 본다

| 사용자 | 시스템 |
|---|---|
| `‹` `›` 를 누르거나 좌우로 민다 | 전날·다음날로 넘어간다 |
| 달력 아이콘을 누른다 | 달력이 뜬다. **운동한 날에 점이 찍혀 있다** |
| 날짜를 고른다 | 그날 화면으로 간다 |
| 종목 카드의 지난 기록을 누른다 | 그 기록이 있던 날짜로 이동한다 |

**이럴 땐 이렇게**
- 기록이 없는 날이면 → 빈 화면 + `[+ 운동 추가]`만 보인다
- **미래 날짜로 가면** → 잡아둔 일정만 보이고, `[+ 운동 추가]` 대신 `[+ 일정 추가]`가 뜬다.<br>안 한 운동을 미리 기록하는 건 막는다

# 6. 고치거나 지운다

| 사용자 | 시스템 |
|---|---|
| 세트의 무게를 누른다 | 그 자리에서 바로 고칠 수 있다 |
| 값을 바꾸고 다른 데를 누른다 | 저장된다 |
| 세트를 옆으로 민다 | 삭제된다 |
| 종목 카드의 `⋮` → 삭제 | 확인 후 종목이 통째로 사라진다 |
| 세션의 `⋮` → 삭제 | 확인 후 세션이 통째로 사라진다 |
| 지운 직후 | "삭제됨 `[실행취소]`"가 5초간 뜬다 |

**이럴 땐 이렇게**
- 3세트 중 2세트를 지우면 → 3세트가 2세트가 된다. 번호가 당겨진다
- 종목을 지우면 → 그 안의 세트도 같이 사라진다
- 세션을 지우면 → 종목·세트가 전부 사라진다. **확인 창을 반드시 띄운다**
- 5초가 지나면 → 되돌릴 수 없다

# 7. 없는 종목을 추가한다

기본 목록이 모든 종목을 담을 수는 없다.
없는 종목을 만났을 때 기록을 포기하거나 비슷한 종목에 억지로 넣는 순간, 데이터를 믿을 수 없게 된다.

| 사용자 | 시스템 |
|---|---|
| `케틀벨스윙`을 검색한다 | 결과가 없고 `+ '케틀벨스윙' 직접 추가`가 뜬다 |
| 그걸 누른다 | 등록 폼. 이름은 이미 채워져 있다 |
| 부위와 기록 방식을 고른다 | (가슴/등/어깨/하체/이두/삼두/코어 · 무게+횟수 / 횟수만) |
| 저장한다 | 시트가 닫히고 **바로 세션에 추가된 상태**가 된다 |
| 다음에 `ㅋㅌㅂㅅㅇ`을 친다 | 나온다 |
| 설정 → 내 종목 | 고치거나 지울 수 있다 |

**이럴 땐 이렇게**
- 초성은 → 알아서 계산된다. 사용자가 입력하지 않는다
- 내가 만든 종목은 → 나만 보인다. 다른 사람 목록에는 안 나온다
- **기록에 이미 쓴 종목을 지우려 하면** → 지우는 대신 목록에서 숨긴다. 지난 기록은 그대로 남는다
- 기본 종목과 이름이 겹치면 → 알려주되, 등록은 막지 않는다

# 8. 운동 일정을 잡는다

일정과 기록은 **따로 존재한다.** 일정만 잡고 안 갈 수도, 일정 없이 갈 수도 있다.
둘이 만나면 연결된다.

| 사용자 | 시스템 |
|---|---|
| 미래 날짜에서 `[+ 일정 추가]` | 일정 폼 (날짜·시간·이름·메모) |
| 저장한다 | 그 날짜에 일정이 표시된다 |
| `[구글 캘린더에 추가]`를 누른다 | 구글 캘린더가 열리고 내용이 채워져 있다. 사용자가 저장을 누른다 |
| 일정을 고치거나 지운다 | 앱 안에서 반영된다 |
| 예정일에 앱을 연다 | 홈 위쪽에 "오늘 예정 · 등 운동"이 보인다 |
| 그걸 누른다 | 그 이름으로 세션이 만들어지고 기록이 시작된다 |
| 일정 없이 그냥 기록한다 | 즉흥 세션으로 남는다 |

**이럴 땐 이렇게**
- **구글 캘린더에 넣은 뒤 앱에서 일정을 지우면** → 구글 캘린더에서는 안 지워진다.<br>이 점을 지울 때 한 줄로 알려준다
- 일정을 잡아놓고 운동을 안 하면 → 그날은 "안 함"으로 남는다
- 일정 하나에 세션은 하나만 연결한다
- 지난 일정을 나중에 기록으로 연결하는 건 → 하지 않는다 (범위 밖)

**왜 이렇게 했나**
구글 캘린더에 직접 쓰고 지우려면 구글의 앱 심사를 통과해야 한다.
개인정보처리방침·홈페이지·데모 영상을 준비해 수 주를 기다려야 하고,
심사 전 상태로 쓰면 **7일마다 재로그인**을 요구받는다.
그래서 일정은 앱이 갖고, 캘린더로는 내보내기만 한다.
나중에 삭제 동기화가 정말 필요하다고 판단되면 그때 심사를 받는다.

# 9. 내 신체 정보를 기록한다

전부 선택 입력이다. 하나도 넣지 않아도 앱을 쓰는 데 지장이 없다.

| 사용자 | 시스템 |
|---|---|
| 설정 → 내 정보 | 신장과 최근 측정값이 보인다 |
| 신장을 넣는다 | 저장된다 (자주 바뀌지 않는 값) |
| `[측정 기록]`을 누른다 | 날짜 + 체중·골격근량·체지방량 입력 |
| 저장한다 | 목록에 쌓인다 |
| 목록을 본다 | 최근 순으로 보이고, **직전 측정 대비 증감**이 같이 뜬다 |

**이럴 땐 이렇게**
- 체중만 알고 나머지는 모르면 → 아는 것만 넣어도 저장된다
- 같은 날 두 번 쟀으면 → 둘 다 남는다. 시간으로 구분한다
- 아무것도 안 넣으면 → 설정 화면에 안내만 있고, 다른 화면엔 아무 영향이 없다

# 10. 앱으로 설치해서 쓴다

| 사용자 | 시스템 |
|---|---|
| 브라우저로 주소에 들어간다 | "홈 화면에 추가" 안내가 뜬다 |
| 홈 화면에 추가한다 | 아이콘이 생긴다 |
| 아이콘으로 실행한다 | 주소창 없이 전체 화면으로 열린다 |

**이럴 땐 이렇게**
- 통신이 불안정하면 → 2번의 저장 방식이 그대로 적용된다
- 오래 안 써서 서버가 잠들어 있으면 → 첫 진입이 몇 초 걸릴 수 있다.<br>이걸 막으려고 며칠에 한 번 서버를 깨우는 작업을 따로 돌린다

# 아직 안 정한 것

| | 왜 필요한지 | 상태 |
|---|---|---|
| 기록 내보내기 (CSV) | **무료 요금제는 자동 백업이 없다.** 기록이 날아가면 복구 수단이 아예 없음 | 넣는 걸 권함 |
| 종목별 기록 전체 보기 | 직전 1회 말고 벤치프레스 이력 전부. 중량 추이를 눈으로 봄 | 미정 |
| 오늘 총 볼륨 요약 | "오늘 가슴 4,200kg" 한 줄. 성취감 장치 | 미정 |
| 세트 완료 체크 | 입력하는 것 자체가 완료라 중복일 수 있음 | 미정 |
| 운동 시간 기록 | 세션 시작~종료. 자동으로 잡을지 수동일지 애매 | 미정 |
